BidLens privacy

Source in. Grounded report out.

Uploaded RFP files and pasted source text are processed in memory for the analysis you request and are not saved by Intelligent Decisions. Source content is sent to OpenAI for analysis. Generated reports, source file name and size, model identifier, account history, and credit events may be retained in your workspace.

Last updated: September 12, 2026

AI processing and deletion

BidLens sends Responses API requests with store: false. This prevents retrievable OpenAI application-state storage, but default abuse-monitoring logs may still retain customer content for up to 30 days unless different approved data controls apply.

Read the complete IDI Privacy Notice, including service providers, retention, and request rights. Contact development@intelligentdecisions.io for deletion or privacy requests.
